# E-Commerce Sales Analysis

## Project Overview
An end-to-end data analytics project exploring e-commerce sales, customer purchasing behavior, and product performance.

## Objectives
- Clean and prepare customer, product, and sales datasets.
- Load structured data into PostgreSQL.
- Analyze sales and customer behavior using SQL.
- Build an interactive Power BI dashboard to communicate business insights.

## Tools & Technologies
- Python: Pandas
- Jupyter Notebook
- PostgreSQL and SQL
- Microsoft Power BI

## Project Workflow
1. Data cleaning and preparation
2. Loading cleaned datasets into PostgreSQL
3. SQL-based analysis
4. Power BI dashboard development
5. Business insights and recommendations

## Repository Structure
- `cleaned_data.ipynb` — data cleaning and preparation
- `e_com.sql` — SQL queries
- `data/` — approved datasets or instructions for obtaining the data
- `power-bi/` — dashboard file and screenshots

## How to Run
1. Install the packages listed in `requirements.txt`.
2. Obtain the approved input datasets and place them in the `data/` directory.
3. Configure a local PostgreSQL database using your own credentials.
4. Run the notebooks in Jupyter.
5. Open the Power BI report in Power BI Desktop.

## Data Privacy
No database passwords or credentials should be committed to this repository. Only datasets approved for public sharing should be included.
